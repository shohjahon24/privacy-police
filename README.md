### One-time setup (30 seconds)

1. Go to **Settings → Pages** in this repository
2. Under **Source**, choose **GitHub Actions**
3. Click **Save**

After that, every push to `main` will automatically publish the page and the URL above will be live. You can also trigger it manually via **Actions → Deploy to GitHub Pages → Run workflow**.
